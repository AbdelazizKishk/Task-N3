Class vs Struct vs Record:
 هما ثلاثة أنواع في C# لإنشاء أنواع بيانات جديدة. الـ class هي Reference Type ومناسبة للكائنات اللي ليها هوية وسلوك زى الطلاب و الكورسات و هكذا محاكاه للواقع شوية،
 والـ struct هي Value Type ومناسبة لتمثيل القيم، أما الـ record فمميزتها الأساسية المقارنة بالقيمة وتقليل الكود المطلوب لتعريف أنواع البيانات.

الـ Indexer هو ميزة في C# بتسمح بالوصول إلى بيانات داخل Object أو تعديلها باستخدام الأقواس المربعة []، بطريقة مشابهة للـ Arrays، مع إمكانية التحكم في القراءة والكتابة عن طريق get وset.
